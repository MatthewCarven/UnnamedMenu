# TODO

Nothing here is blocking. `um` does the job as specified; these are the ideas
that came up while building it and were deliberately left out for want of a
real use case.

## For you

- [ ] Remove the stray empty `.git` from the neighbouring `TUI` folder if that
      init was a slip — it has no commits, so `Remove-Item -Recurse -Force .git`
      loses nothing.
- [ ] Pushing to a remote, whenever you want one.

## Likely worth doing when a use case appears

- [ ] **Read the spec from stdin** (`um -f -`), so a menu can be generated by
      another program. Currently conflicts with the no-console fallback, which
      reads the user's answer from stdin — would need `-f -` to imply that
      selection must come from the console or from `-d`/`-w`.
- [ ] **Multi-select** (space to toggle, Enter to confirm, emit all chosen
      commands). Straightforward; the item struct already has room. No use case
      yet, and it complicates the exit-code contract.
- [ ] **`!default N` and `!wait N` directives** in menu files, so a menu file
      is fully self-describing rather than needing `-d`/`-w` on the call.
- [ ] **Per-item hotkey override** in menu files, e.g. `&Restore` to bind `R`.
      Nicer for a recovery drive than positional digits, since inserting an
      entry currently renumbers everything below it.

## Smaller

- [ ] Scroll long menus that do not fit the console window. Currently a menu
      taller than the window relies on the buffer scrolling, which works but
      pushes the title off screen.
- [ ] `--no-color` for terminals or capture tools that dislike attributes.
- [ ] Sub-menus — an item whose command is another `um` call already works, but
      returning to the parent menu needs a loop in the batch file. A `!submenu`
      directive could make it declarative.

## Explicitly decided against

- **Expanding environment variables inside `um`.** The shell already does it,
  and doing it twice causes far more surprises than it solves. See
  docs/GOTCHAS.md §1.
- **Interpreting the command in any way.** The string goes to `cmd /c`
  verbatim or is printed verbatim. Every attempt to be clever here would break
  someone's redirection.
- **Guessing when name and command counts disagree.** It errors instead. On a
  drive that can reformat disks, a menu that silently pairs up wrong is worse
  than one that refuses to start.
